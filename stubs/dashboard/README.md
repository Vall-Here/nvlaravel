# System Templates (Stubs)

Semua file dan folder yang diletakkan di dalam direktori `dashboard` ini akan di-*copy paste* secara langsung ke dalam instalasi Laravel baru jika *user* memilih opsi "Full Admin System".

Struktur folder di dalam sini harus sama persis dengan struktur Laravel (misal: `app/Http/Controllers`, `resources/views`, `routes`).

Contoh:
Jika Anda ingin menyuntikkan `UserController.php`, letakkan di:
`stubs/dashboard/app/Http/Controllers/UserController.php`
